# Sellbird — AI-Powered Cold Outreach Platform

Sellbird (formerly Harvey) is an open-source outreach platform that runs on Claude Code or ChatGPT Codex. It automates the entire cold outreach pipeline:

1. **Discover** — Finds businesses matching your ideal customer profile
2. **Profile** — Visits websites, collects buying signals (29 signal types)
3. **Enrich** — Finds owner/contact emails via pattern detection + verification
4. **Write** — Generates personalized 3-email sequences (strict anti-AI-language rules)
5. **Send** — Delivers from your own mailbox with human-like pacing
6. **Handle** — Reads replies, classifies intent, advances conversations toward meetings

## Quick Setup

### 1. Install dependencies
```bash
cd d:\Nebulyx\scratch\sellbird-temp
python -m venv .venv
# Windows:
.venv\Scripts\activate
pip install -e .
```

### 2. Configure credentials
```bash
copy .env.example .env
# Edit .env with your API keys (email provider, verification service, etc.)
```

### 3. Train on your product
```bash
sellbird train https://your-website.com
# OR let Claude guide you:
# claude   (then say "set up Sellbird for me")
```

### 4. Confirm signals
```bash
sellbird signals --confirm free    # Enable free signals
```

### 5. Find businesses
```bash
sellbird discover                  # Free OpenStreetMap source
```

### 6. Run
```bash
sellbird run                       # Start the heartbeat loop
sellbird dashboard                 # Web UI at http://127.0.0.1:5555
```

## Key Commands

| Command | Purpose |
|---|---|
| `sellbird run` | Start the heartbeat loop (checks every 15 min) |
| `sellbird dashboard` | Web UI with pipeline, outbox, analytics |
| `sellbird setup` | Interactive setup wizard |
| `sellbird train <url>` | Train on a product website |
| `sellbird status` | Pipeline summary |
| `sellbird usage` | Claude quota + per-agent token usage |
| `sellbird export` | Export prospects to CSV |
| `sellbird signals` | View/confirm buying signals |
| `sellbird discover` | Find businesses (estimates cost first) |
| `sellbird outbox` | Review queued emails |
| `sellbird warmup` | Check sending domain readiness |
| `sellbird sending pause` | Emergency stop all outbound |

## Architecture

- **Heartbeat loop** — Every 15 min: check quiet hours → budget → decide → act → log → sleep
- **5 Sub-agents**: Scout (prospecting), Writer (emails), Sender (delivery), Handler (replies), Analyst (stats)
- **SQLite database** at `data/sellbird.db`
- **Skills library** in `skills/` — plain Markdown, edit to change behavior
- **Dashboard** — FastAPI + plain HTML/CSS/JS, no build step

## Safety

- Every email waits in Outbox for approval (until you enable autopilot)
- Pre-send checks reject: unfilled merge tags, banned phrases, overlong emails, extra links
- Daily send limits, quiet hours (22:00–07:00), and bounce-rate kill switch
- Runs locally — no data leaves your machine except emails you approve
- All actions logged in SQLite for full auditability
